    How this works

    Every listing is described by a handful of traits read from its title, location, and term, and from the degrees Simplify lists. When you apply to a role or mark one Not for me, the profile counts it toward that role’s traits. A trait you keep passing on and never apply to weighs against similar listings. Once you’ve passed on ten roles, listings that add up low enough move from For you to Set aside, each with the reason.

    Rules you set here move listings to Set aside too, and All listings ignores the profile entirely. A pass without a reason counts half against each of the job’s traits, since most of them probably weren’t the problem; a reason makes the traits it names count double. Older feedback fades, counting half as much after a month.

    All of this is stored in this browser only. The download includes your applications as well.
